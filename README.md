  <h2 style="color: #f39c12; text-transform: uppercase; margin-top: 0;">🌐 ABOUT THIS GAME / INFORMAZIONI SUL GIOCO</h2>
  <p><b>[EN]:</b> Parolando is an 8-bit retro arcade word game set in Italy. Challenge smart difficulty-based bots (Tourists, Locals, and Grannies), type words under time pressure, enjoy procedural pixel art graphics, and listen to an immersive built-in Web Audio API digital tarantella synthesizer.</p>
  <p><b>[IT]:</b> Parolando è un gioco di parole in stile arcade retro 8-bit ambientato in Italia. Sida bot intelligenti basati su diverse difficoltà (Turisti, Locali e Nonne), componi parole sotto pressione temporale, goditi la grafica pixel art procedurale e ascoltati la colonna sonora digitale generata nativamente con la Web Audio API.</p>
